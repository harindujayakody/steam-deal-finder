Getting an IsThereAnyDeal API key

This is optional — rupee conversion and Steam pricing work with no key at all. A free key unlocks two things: the 6-month best-deal tracker (and its toolbar dot) and the other-stores price comparison (EA, GOG, Epic, Ubisoft, Battle.net). It takes about two minutes.

  1. Create an IsThereAnyDeal account
    Go to isthereanydeal.com and sign up — email, or sign in with Steam/Google/etc. It's free.
  2. Register an app
    Open isthereanydeal.com/apps/my and click Add application. Give it any name you like — e.g. "Steam Deal Finder (personal)" — this is just a label for your own reference, it doesn't need a public website.
  3. Copy your API key
    Once the app is created, its page shows an API key — a short string of letters and numbers. Copy it.
  4. Paste it into Steam Deal Finder
    Open Settings, paste the key into the IsThereAnyDeal section, click Test to confirm it works, then Save settings.
That's it — reload any Steam store page and the best-deal and other-stores sections will start populating.

Common questions

Do I need an API key to use Steam Deal Finder?
No. Rupee conversion, the region comparison, and the watchlist all work with no key. The key only unlocks the two ITAD-powered sections.
Is my API key sent anywhere else?
No — it's stored in your browser's local extension storage and sent only to IsThereAnyDeal's own API, exactly as needed for each lookup.
Why don't EA or Battle.net ever show up in "Other stores"?
IsThereAnyDeal tracks very few EA or Battle.net listings — both are largely exclusive to their own launchers. GOG, Epic, and Ubisoft show up far more often; this isn't a bug.
The 6-month best-deal card says "no history recorded" — why?
ITAD only has data for titles it has tracked a price change for in the window. New or rarely-discounted titles may simply have nothing recorded yet.
