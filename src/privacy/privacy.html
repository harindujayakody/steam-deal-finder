Privacy Policy & Data Security Disclosures. Effective Date: July 2026.

1. Overview

Steam Deal Finder ("the Extension") is committed to protecting your privacy and security. This Privacy Policy outlines how the Extension operates, how local data is handled, and our zero-tracking data practices.

Summary: Steam Deal Finder does NOT collect, store, transmit, or sell any personal data, user accounts, browsing history, or telemetry. All preferences and watchlists remain 100% local on your device. Zero Analytics

2. Data Collection & Processing

We operate under strict data minimization principles:

  • No Personal Information: We do not collect names, email addresses, IP addresses, credentials, or payment details.
  • No Browsing Activity Tracking: The Extension does not track, log, or monitor your web browsing history. It functions only when you view Steam store pages (store.steampowered.com) to display currency conversions.
  • Local Device Storage (chrome.storage): All user settings (alert triggers, watchlist items, custom exchange rate overrides, and optional API keys) are stored locally on your device. This data is never sent to us or any central server. Your optional IsThereAnyDeal API key is kept in on-device-only storage (chrome.storage.local) and is never synced to your Google account or other devices; other settings use Chrome sync so they follow your profile.

3. External API Services

To calculate accurate LKR pricing and deal history, the Extension makes direct requests only to the following declared endpoints:

  • ExchangeRate.fun API (api.exchangerate.fun), with open.er-api.com as fallback: Used to fetch public, hourly-updated USD-to-LKR exchange rates. If the primary source is unreachable, the extension retries with the fallback source before using a cached rate. No user identifiers or tokens are included in these requests.
  • Steam Store API (store.steampowered.com): Used to fetch game titles, regular prices, and current sale discounts for active store pages.
  • IsThereAnyDeal API (api.isthereanydeal.com): Optional. Used only if you configure an ITAD API key to query 6-month historical deal pricing.

4. Data Selling & Sharing Policy

In accordance with Google Chrome Web Store Developer Program Policies:

  • We do NOT sell, trade, or rent user data to third parties.
  • We do NOT process or transfer user data for advertising, credit evaluation, or profiling.
  • We do NOT inject third-party ads, affiliate link rewrites, or trackers.
